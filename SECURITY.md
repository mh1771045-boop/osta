# Security

Osta runs locally and does **not** sandbox the agent. The permission prompts help you see what the agent is about to do; they are not a security boundary. For real isolation, run Osta inside a container or a virtual machine.

To report a vulnerability, contact the maintainer privately on [WhatsApp](https://wa.me/201206580045) instead of opening a public issue. Issues that also affect opencode should be reported upstream as described in [opencode's security policy](https://github.com/anomalyco/opencode/blob/dev/SECURITY.md).
