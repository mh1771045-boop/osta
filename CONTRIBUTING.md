# Contributing to Osta

Bug reports and pull requests are welcome.

- Run Osta from source with `bun install` and `bun dev`.
- Run the tests of the package you change, for example `cd packages/core && bun test`.
- Keep changes in the style of the surrounding code. Code, comments and commit messages are in English.
- After merging upstream opencode changes, run `bun script/osta/rebrand.ts` to re-apply Osta's naming.

AGENTS.md describes the codebase conventions inherited from opencode.
