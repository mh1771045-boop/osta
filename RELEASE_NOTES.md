# Osta 0.1.0

The first release of Osta (أسطى), an open-source AI coding agent based on opencode.

### Highlights
- **Free with no API key**: Osta starts on free models; GitHub Copilot Free and local models are one step away.
- **A craftsman's way of working**: every model follows Osta's understand, decide, act, verify, report, learn loop.
- **Learning memory**: lessons go to `.osta/learnings.md` and `~/.config/osta/learnings.md` and load in every session.
- **Arabic and English**: Osta replies in the language you write in.

### Install
```bash
curl -fsSL https://raw.githubusercontent.com/mh1771045-boop/osta/main/install | bash
```
